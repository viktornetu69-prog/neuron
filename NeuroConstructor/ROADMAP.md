## 🎓 Stage 2: Студент-преподаватель архитектура

**Статус:** 🔄 В прогрессе (85%)  
**Цель:** Реализовать конвейер обучения "студент-преподаватель" со сжатием моделей.

### Планируется:
- [ ] Загрузка моделей (.gguf, .pt, .safetensors)
- [ ] Конвертация моделей (`model_converter.py`)
- [ ] Система сжатия (квантование, обрезка весов)
- [ ] Шаблон студенческой модели (`student_template.json`)
- [ ] Интерфейс управления моделями

### Ответственные файлы:
- `NeuroConstructor.Core/core/model_loader.py`
- `NeuroConstructor.Core/core/model_converter.py`
- `NeuroConstructor.Core/core/real_quantizer.py`

### 📁 Необходимые файлы моделей (в папке `NeuroConstructor.Core/models/`):
| Файл | Назначение | Статус |
|------|------------|--------|
| `Qwen3-4B-Thinking-2507-Q4_K_M.gguf` | Teacher-модель Qwen3 4B (Q4_K_M quantization) | ✅ **Доступна локально** (не загружена в Git по требованию) |
| `student_template.json` | Шаблон студенческой модели (создаётся автоматически при `CreateStudentModel`) | ✅ Есть в репозитории |

⚠️ **Важно:** Реальная модель `Qwen3-4B-Thinking-2507-Q4_K_M.gguf` находится в рабочей папке проекта, но **не загружена в Git** по требованию. Код Stage 2 готов к загрузке модели — достаточно указать путь к файлу при вызове `LoadTeacherModel`. Модель имеет 4B параметров с квантованием Q4_K_M, что идеально подходит для демонстрации конвейера студент-преподаватель.

**Как использовать модель:**
1. Убедитесь, что `Qwen3-4B-Thinking-2507-Q4_K_M.gguf` находится в `NeuroConstructor.Core/models/`
2. Вызовите `LoadTeacherModel` с путем к файлу: `model_path="NeuroConstructor.Core/models/Qwen3-4B-Thinking-2507-Q4_K_M.gguf"`
3. После загрузки можно вызывать `CreateStudentModel` для создания сжатой версии
