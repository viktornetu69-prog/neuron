# 🗺️ Дорожная карта NeuroConstructor

## Обзор

Дорожная карта описывает этапы развития проекта NeuroConstructor — системы для создания, тестирования и оптимизации нейросетевых моделей в игровой разработке.

## 🚀 Stage 1: MVP — Базовое gRPC-соединение

**Статус:** ✅ Завершён  
**Цель:** Установить связь между C# UI и Python Core через gRPC.

### Выполнено:
- [x] Структура проекта (.NET WPF + Python)
- [x] gRPC сервис (`engine.py`) с методами Chat и GetStatus
- [x] Protobuf definición (`NeuroConstructor.proto`)
- [x] C# UI (`MainWindow.xaml`, `MainWindow.xaml.cs`)
- [x] Python сервер (`start_server.py`)
- [x] Обновление конфигураций и импортов

## 🎓 Stage 2: Студент-преподаватель архитектура

**Статус:** 🔄 В прогрессе (40%)  
**Цель:** Реализовать конвейер обучения "студент-преподаватель" со сжатием моделей.

### Планируется:
- [ ] Загрузка моделей (.gguf, .pt, .safetensors)
- [ ] Конвертация моделей (`model_converter.py`)
- [ ] Система сжатия (квантование, обрезка весов)
- [ ] Шаблон студенческой модели (`student_template.json`)
- [ ] Интерфейс управления моделями

### Ответственные файлы:
- `NeuroConstructor.Core/core/model_loader.py`
- `NeuroConstructor.Core/core/model_converter.py`
- `NeuroConstructor.Core/core/real_quantizer.py`
